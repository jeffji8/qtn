# 理想汽车报价单（QTN V3.0）

一款轻量、响应式的理想汽车购车报价工具。选择车型、选装、购车权益、政府补贴和金融方案后，可自动计算开票价、购置税、首付、月供、总利息与实际花费，并生成适合保存和分享的图片报价单。

> 当前版本：V3.0 Beta · Design by Jeff

## 功能亮点

- 支持手机、平板和电脑，适配 Web App 使用场景
- 桌面端采用左侧配置、右侧实时报价的双栏布局
- 自动计算开票价、保险、购置税、购车总价及补贴后实际花费
- 支持车型专属选装、购车权益及互斥规则
- 支持全款、随心还、免息和低息等多种金融方案
- 支持按比例或金额调整首付，并自动显示最低首付
- 支持报废补贴、置换补贴、石景山补贴和手动补贴
- 支持手动添加临时优惠及补贴
- 一键生成图片报价单，可长按或右键保存

## 使用方法

1. 选择车型并确认保险预估金额。
2. 按需选择外观、配置及购车权益。
3. 选择政府补贴或添加其他优惠、补贴。
4. 选择全款或金融方案；分期时设置首付及期数。
5. 查看右侧实时结果，点击“生成图片报价单”保存或分享。

## 本地运行

本项目是纯静态页面，无需安装依赖。下载仓库后直接打开 `index.html` 即可使用。

如浏览器限制本地资源，可在项目目录启动任意静态服务器，例如：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 部署

可部署到 GitHub Pages、Cloudflare Pages、Netlify、Vercel 或任意静态网站托管服务。

使用 GitHub Pages 时，在仓库的 `Settings → Pages` 中选择从 `main` 分支根目录部署即可。

## 数据维护

主要业务数据集中在 `index.html` 的以下配置项中：

- `carData`：车型、指导价、保险及金融配置
- `optionalConfigMap`：车型选装项目
- `optionalDiscountMap`：现金优惠、全款优惠、选配基金等权益
- `extraDiscountMap`：复购等附加优惠
- `FINANCE_PROFILES`：各车型可用金融方案
- `SUI_XIN_HUAN_CONFIG`：随心还最低首付及费率

修改业务数据后，建议逐项检查车型切换、权益默认状态、互斥逻辑、开票价、购置税和金融计算结果。
